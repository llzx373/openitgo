# OpenItGo Fluent 2 修正计划

基于 Fluent 2 官方设计原则与当前 Windows 实际界面审查。目标是修复响应式、可访问性、信息层级和反馈一致性问题，同时保留阅读沉浸感、双栏文件管理器效率与现有业务行为。

## 执行规则

- 按阶段实施，每项完成后将 `[ ]` 改为 `[x]`，并记录验证结果。
- 每个逻辑阶段独立提交；不把无关重构混入 UI 修正。
- 每阶段至少运行 `cargo fmt --all`、`cargo check --workspace` 和相关测试；阶段结束运行完整工作区测试与 Clippy。
- Windows 主题以 Fluent 2 为基准；macOS 与其他主题保持平台特色。
- 不把文件管理器改成宽松卡片界面，不滥用阴影、透明材质和动画，不改变文件操作与阅读业务语义。

## 阶段 1：共享控件与可访问性

### 按钮与焦点

- [x] 统一标准、主要、轻量、危险按钮及图标按钮的状态和尺寸。
- [x] 所有图标按钮提供中文辅助名称，完整支持默认、悬停、按下、选中、焦点和禁用状态。
- [x] 焦点使用明确外描边，不能只依赖背景变化。
- [x] 收敛漫画工具栏与文件管理器顶栏的重复按钮样式。

### 控件语义与键盘

- [x] 开关辅助名称由调用方传入，不再统一暴露为“开关”。
- [x] 分段标签提供控件角色、名称、选中状态、焦点环和方向键导航。
- [x] 书架卡片提供标题、类型、进度等辅助信息，支持 Enter 打开和 Shift+F10 菜单。
- [x] 自绘可点击区域全部具备可见键盘焦点。

### 共享对话框

- [x] 建立统一标题、正文、辅助说明和底部操作区。
- [x] 统一 Esc、Enter、初始焦点和关闭后焦点恢复。
- [x] 模态打开时阻止背景误触，内容过高时正文滚动且操作区保持可见。
- [x] 危险确认默认聚焦取消，并逐步迁移清空、解压和文件操作对话框。

### 验收

- [x] 仅用键盘可切换设置、操作开关、打开卡片及其菜单、确认或取消对话框。
- [x] UI 自动化树中图标按钮和开关具有唯一可读名称。
- [x] 共享控件纯逻辑测试、完整工作区测试与 Clippy 通过。

## 阶段 2：响应式工具栏与命令收纳

- [x] 建立命令分组、优先级和溢出菜单规则，空间不足时不裁切控件。
- [x] 漫画、电子书和媒体工具栏按导航、模式、页面、视图、其他操作分组。
- [x] 翻页、播放、搜索等当前任务关键命令优先保留，低频命令先进入“更多”。
- [x] 溢出菜单保留命令快捷键、选中状态和辅助名称。
- [x] 全屏下打开溢出菜单时工具栏不自动隐藏。
- [x] 书架窄窗口拆分为标题/标签与搜索/筛选两行，管理操作按需收纳。
- [x] 文件管理器保留单双栏、快览、树、视图、搜索和任务，将配置型操作移入溢出菜单。
- [ ] 1024、1366、1920 逻辑宽度及高 DPI 下无重叠、裁切和布局跳动。

## 阶段 3：书架与消息反馈

### 书架卡片和空状态

- [x] 修复浅色主题无封面占位文字几乎不可见的问题。
- [x] 区分封面加载中、无封面、生成失败和源文件已删除。
- [x] 整张卡片统一悬停、按下、焦点和点击表现。
- [x] 增加与右键菜单共用的“…”操作入口。
- [x] 标题截断时可通过悬停或聚焦查看完整标题。
- [x] 区分初始空书架、搜索无结果、标签筛选无结果及其他标签页空状态。
- [x] 清空书架改为明确确认对话框，说明不删除源文件，默认聚焦取消。

### 消息反馈

- [x] 建立信息、成功、警告、错误四级共享消息组件。
- [x] 关于、末尾提示不再使用错误红色。
- [x] 普通消息不推动页面布局，错误不会被普通状态立即覆盖。
- [x] 消息具有图标、级别、可读文本和关闭能力，并正确暴露辅助语义。

### 验收

- [x] 浅色和深色下所有占位与缺失状态可读。
- [x] 搜索无结果不再显示首次导入引导。
- [x] 清空书架取消路径不修改数据。
- [x] 信息、末尾提示与真实错误视觉语义不同。

## 阶段 4：文件管理器与设置页

### 文件管理器

- [x] 提供紧凑/舒适密度，保持选择、排序、框选、虚拟化与键盘逻辑一致。
- [x] 密度切换保留焦点项、选择和合理滚动位置。
- [x] 目录名默认使用正文色，强调色主要用于选中、焦点和主要操作。
- [x] 符号链接和隐藏文件保留非颜色提示，选中行具备背景与状态标记。
- [x] 小图标按钮保持足够点击区域。

### 设置与快捷键

- [x] 去除重复页面/分组标题，统一 Regular/Semibold 字体层级。
- [x] 快捷键页改为操作、已绑定按键、新按键、添加的固定列。
- [x] 修复删除符号显示，添加/删除按钮提供明确辅助名称。
- [x] 快捷键冲突和无效输入在对应行内反馈，编辑完整支持键盘。
- [x] 设置提升为全局可见入口，保留菜单和快捷键，返回时恢复来源视图。

### 验收

- [x] 两种文件管理器密度功能一致且状态不丢失。
- [x] 大量目录列表不再由强调色主导。
- [x] 快捷键列对齐稳定，输入与按钮不随已有按键数量跳动。

## 阶段 5：字体、动效与视觉收尾

- [x] 补齐 Regular/Semibold 的真实字体或明确回退策略，统一正文、辅助、组标题和页面标题。
- [x] 检查中文、英文、数字和图标混排基线；正文对比度至少 4.5:1，大文字至少 3:1。
- [x] 工具栏、状态栏和共享对话框使用 120ms 的功能性进入/退出淡化。
- [ ] 菜单进入/退出动效：egui 0.35 的 Popup 没有统一退出动画通道，暂不伪造完成，需专项封装。
- [x] 顶层页面只使用快速淡化，不使用大幅滑动。
- [x] 增加统一“减少动态效果”，覆盖漫画、电子书、工具栏、菜单和对话框，并考虑 Windows 系统设置。
- [x] 统一 16/20px 图标尺寸、视觉粗细与对齐，小图标不作为唯一状态提示。
- [x] 卡片继续使用细描边；菜单、浮层和对话框使用共享层级/阴影令牌。
- [x] 浅色、深色、高对比度和系统强调色分别评估；macOS 只共享交互原则，不套用 Windows 外观。

评估记录：浅色/深色正文和次要文字有自动对比度测试；系统强调色与专用高对比度令牌暂未接入，属于后续增强。macOS 保持现有原生视觉。
