# 文件管理器 vs Total Commander：功能差距盘点

> 目的：对照 Total Commander（以下简称 TC）的成熟功能集，盘点当前
> `FileManagerView` 已做与未做的部分，作为后续排期依据。
>
> 本文已更新至**二期收尾（阶段 AJ）后的当前现状**：§一–§四全部按
> 一期（阶段 A–N，commit `567fb90`–`58d2b7f`）+ 二期（阶段 O–AI，commit
> `2d9a60d`–`2fe603f`）实现后的行为改写，§五改为实施记录。
> 「弱化」指做了但比 TC 弱；「有意不同」指刻意走了别的路线，本节保留说明。
>
> TC 功能集参考：Total Commander 11.x 官方 feature list +
> [totalcmd.net 功能维基](https://www.ghisler.com/)。

---

## 一、核心功能差距（按模块）

### 1. 面板与标签

| # | TC 功能 | 现状 | 差距说明 |
|---|---------|------|----------|
| 1.1 | 面板内多标签（Ctrl+T 新建 / Ctrl+W 关闭 / Ctrl+Tab 切换） | ✅ 已实现（阶段 G/AI） | 每栏独立标签：Ctrl+T 复制当前目录开新标签、Ctrl+W / 中键 / × 按钮关闭（剩 1 个时 no-op）、Ctrl(+Shift)+Tab 循环切换；锁定标签（锁图标）导航原地开新标签、双击/右键重命名自定义标题；会话恢复（fm_tab_groups，路径 + 活跃索引 + 焦点 + 选中）；标签组另存/载入 |
| 1.2 | 驱动器按钮栏（每栏顶部一排盘符按钮） | 弱化 | 面包屑最左有驱动器菜单（点击枚举可列盘符），够用；没有 TC 那种一排可点按钮和 Ctrl+F1/F2 |
| 1.3 | 驱动器信息（按钮栏显示每盘剩余空间） | 无 | 状态栏已显示当前盘剩余空间（阶段 Q）；无每盘独立显示 |
| 1.4 | 面板间拖拽复制/移动（拖到另一栏） | ✅ 已实现 | 栏间拖拽 → 复用确认对话框执行复制；悬停高亮目标栏；单栏模式不启用；确认可关闭（fm_drag_confirm） |
| 1.5 | 历史/常用目录（Alt+↓ 历史下拉、Ctrl+D 目录热表） | ✅ 已实现 | 常用目录书签：两栏共享、★ 菜单管理（新增/删除/重命名、分组子菜单，fm_bookmark_groups 持久化，旧扁平 fm_bookmarks 读取兼容迁移）、点击跳转经 fallback_existing_dir 回退；Ctrl+D 开/关焦点栏书签菜单（阶段 P）；Alt+↓ 各栏独立导航历史下拉（阶段 B） |
| 1.6 | 目录历史后退/前进 | ✅ 已实现 | 每栏独立导航历史（Vec + 位置指针，前进分支在 navigate_to 时截断）；Alt+←/→ 与面包屑 ‹ › |
| 1.7 | 面包屑导航 | ✅ 已实现 | 段点击跳转、后退/前进按钮、铅笔按钮编辑路径（绝对/相对/环境变量，阶段 M）、溢出折叠下拉、星标书签菜单、驱动器菜单；面包屑段同时是栏内拖放落点（阶段 Z） |
| 1.8 | 快速查看面板（Ctrl+Q，对侧栏预览文件内容） | ✅ 已实现（阶段 D） | Ctrl+Q 快览：双栏下非活动栏整栏替换为预览（焦点跟随选中项）；与 F3 预览共用内容管线（图片嗅探/文本嗅探 chardetng/音视频 mpv 截图帧）；F3 底栏预览面板开关记忆 fm_preview_open |
| 1.9 | 树形面板（Ctrl+F8 或单独的 Tree 面板） | ✅ 已实现（阶段 AH） | Alt+F10 把非活动栏整栏替换为目录树（与 Ctrl+Q 快览互斥）：懒加载展开、打开时锚定活动栏目录、单击选中/双击导航、Esc/Alt+F10 关闭 |
| 1.10 | 分支视图（Ctrl+B：当前目录及子目录全部文件平铺） | ✅ 已实现（阶段 E） | Ctrl+B 切换；过滤/排序/选择照常；双击目录行进入对应子目录；列举有截断上限提示 |
| 1.11 | 并排同步滚动 / 同步切换目录（SyncDirs） | ✅ 已实现（阶段 AE） | 「同步目录」对话框：双向/左→右/右→左、递归对比、按大小+mtime 分类（仅左/仅右/左新/右新/相同；大小相同 mtime 差 ≤2s 视为相同，FAT 精度），虚拟化预览列表（Same 默认隐藏可开），生成复制（覆盖）/删除（回收站）任务组入任务队列执行 |
