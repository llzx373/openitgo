# 文件管理器 vs Total Commander 差距清单

对比基准：Total Commander 10/11（默认配置 + 常见使用习惯）。
现状来源：`openitgo-app/src/views/file_manager*.rs`、`file_ops.rs`、
`preview_bytes.rs`（2026-02 盘点）。按「功能 / 操作 / 外观 / 使用习惯」四维度列出，
每项标注差距性质：**缺失**（完全没有）/ **弱化**（有但不完整）/ **有意不同**（设计取舍）。

> 注：§一–§四正文表格保留 2026-02 盘点原貌不再逐行修订；其后的迭代实现
> （阶段 A–N，对应 commit `567fb90`–`58d2b7f`）以 §五 各优先级条目上的
> ✅ 标注为准。

## 一、功能差距

### 1. 栏与窗口结构

| TC | 现状 | 性质 |
|---|---|---|
| 栏内**标签页**（Ctrl+T 新建、Ctrl+W 关闭、Ctrl+Tab 切换、锁定标签、标签重命名、保存标签组） | 无标签页，每栏仅一个目录 | 缺失，大差距 |
| 底部**命令行输入条**（可直接执行命令、Ctrl+P 把当前路径送进去、Ctrl+Enter 把选中文件名送进去） | 无 | 缺失 |
| 顶部**按钮栏**（用户自定义按钮：程序、命令、菜单） | 无 | 缺失 |
| 两个独立**驱动器按钮栏**（每栏一排驱动器按钮，Alt+F1/F2 弹驱动器菜单） | 面包屑最左一个盘符下拉（两栏各自有） | 弱化，够用 |
| 树形面板模式（Alt+F10，一栏变目录树） | 无 | 缺失 |
| Ctrl+Q **快速查看**：另一栏整体变成预览面板（双栏下的常驻预览） | 预览仅存在于单栏模式右半 + 双栏 F3 临时弹窗 | 弱化 |

### 2. 显示模式

| TC | 现状 | 性质 |
|---|---|---|
| Brief（仅名称多列）/ Full（详细列）/ **缩略图视图** | 仅详细列表一种 | 缺失（缩略图对漫画/图片场景价值高） |
| **分支视图**（Ctrl+B：当前目录+所有子目录文件扁平列出） | 无（Archive 视图有 flat_all，FM 没有） | 缺失 |
| **自定义列视图**（可增删列、按属性/插件字段配置多套列布局） | 固定三列：名称/大小/时间 | 弱化 |
| 按文件类型**着色规则**（如 .exe 红色、临时文件灰色） | 无（仅图标区分类型） | 缺失 |
| 文件**注释**列（descript.ion） | 无 | 缺失 |
| 显示系统**真实文件图标**（exe 内嵌图标、图片缩略图图标） | 统一 phosphor 字体图标（7-8 种类型） | 弱化 |

### 3. 选择与过滤

| TC | 现状 | 性质 |
|---|---|---|
| Num+ / Num− **通配符选择/取消选择组**（如 `*.zip`、`EP*`） | 无，过滤框只支持子串匹配、不支持通配符 | 缺失 |
| Num* **反选** | 无反选 | 缺失 |
| 灰色 +/− 仅选择/取消**文件**（不动目录） | Ctrl+A 全选含目录，无「只选文件」变体 | 缺失 |
| Insert / 空格 **勾选当前项并下移**（可只勾不选，红名标记选中集） | 空格 = 计算目录大小；勾选只有 Ctrl+单击 / Ctrl+方向键+无空格配合 | 弱化 |
| **快速搜索**（字母键直接跳到匹配项 / Ctrl+S 增量搜索框 / Alt+字母仅过滤显示） | 无字母定位；过滤要鼠标点顶栏输入框 | 缺失，高频痛点 |
| 过滤支持**通配符与正则**、可保存过滤方案 | 仅不区分大小写子串 | 弱化 |
| 鼠标**框选**（可配置右键拖动框选） | 拖动 = 拖放 payload，无框选 | 缺失 |
| 保存/恢复选择集 | 无 | 缺失 |

### 4. 排序

| TC | 现状 | 性质 |
|---|---|---|
| 更多排序键：扩展名、属性、无排序（物理顺序） | 名称/大小/时间三个键 | 弱化（缺**按扩展名**，常用） |
| 每目录记忆排序（可配） | 全局单一排序（仅活动栏持久化） | 弱化 |
| 目录置顶可开关 | 目录恒置顶（不可关） | 有意不同 |

### 5. 文件操作引擎

| TC | 现状 | 性质 |
|---|---|---|
| **执行期逐个冲突询问**（覆盖/跳过/重命名/追加，带缩略图对比、全部应用选项） | 策略操作前一次性确定；「询问」档执行期按跳过处理 | 有意不同（简化），但「询问」语义被吞 |
| 复制进度窗：**速度、剩余时间、独立窗口、可暂停**、后台化（F2 放后台继续操作） | 状态栏一条 160pt 进度条，仅百分比，无速度/ETA，无暂停，操作时 UI 虽可动但同栏被刷新干扰 | 弱化 |
| **传输队列**（多任务排队、队列管理器） | 每任务独立线程并行，无队列管理 | 缺失 |
| 复制后**校验**（写入后重读比对） | 无 | 缺失 |
| 分割/合并文件 | 无 | 缺失 |
| 校验和计算/校验（CRC32/MD5/SHA） | 无 | 缺失 |
| 修改属性/时间戳 | 无 | 缺失 |
| **多格式打包**（zip/tar/gz + 插件 rar/7z；Alt+F5） | 仅写出 zip（引擎在 parser，支持读多格式） | 弱化 |
| 撤销（undo） | 无（删除走回收站可挽回，复制/移动不可撤销） | 缺失 |

## 二、操作习惯差距

1. **选中即复制目标**：TC 无选中集时对焦点项操作——已对齐（`op_targets` 回退焦点项）。
2. **确认习惯**：TC F5/F6 默认弹一次确认框（含目标路径可改、仅复制所选类型过滤、
   仅复制指定日期后文件等扩展选项），执行中冲突再问。现状确认框只有目标路径 +
   冲突策略，无「仅复制部分文件」扩展选项。
3. **进度反馈粒度**：TC 显示文件名 + 总进度 + 单文件进度 + 速度 + ETA；
   现状只有总百分比 + 当前文件名，无单文件进度（大文件复制时进度条长时间不动）。
4. **删除习惯**：TC 默认 F8 物理删除、Shift+Del 直删可选、Del 到回收站（可配）；
   现状一律回收站（更安全，属于有意不同）。
5. **移动语义**：TC 跨盘移动成功后源物理删除；现状源进回收站（更安全，有意不同）。
6. **焦点跟随**：TC 操作完成后焦点落在下一项 / 新项；现状重命名/新建后选中新项
   （已对齐），复制/移动后焦点行为未定义（依赖刷新保留选中）。
7. **刷新时机**：TC 依赖 FS watch + 手动 Ctrl+R（F5 是复制）；现状 watch 非递归
   300ms 去抖自动刷新（已对齐并更好），但子目录内变化不触发。
8. **错误报告**：TC 操作结束弹汇总窗可逐项重试；现状 toast 式 error_message 报前 3 项。
9. **后台继续工作**：TC 复制可放后台，继续浏览操作；现状操作线程后台跑、UI 不阻塞
   （已对齐），但无任务列表查看多个在途任务。

## 三、外观差距

1. **图标**：TC 显示系统真实图标（含 exe 图标、图片缩略图）；现状为字体图标
   （统一风格但辨识度低，区分不了同名不同类型文件的具体内容）。
2. **缩略图模式**：无（对漫画阅读器用户的图片目录价值最高）。
3. **颜色定制**：TC 可按文件类型/属性定义前景色，整体主题可换肤；现状跟随
   egui 全局主题，FM 无独立配色入口。
4. **字体/行高可配**：TC 可调列表字体字号行距；现状固定（行高 22pt 与全局缩放走）。
5. **列布局持久化**：TC 记住列宽/列顺序/每标签布局；现状列宽与 col_shift 仅会话内。
6. **状态栏信息密度**：TC 显示选中数/总大小/驱动器剩余空间/过滤状态；
   现状只有数量与路径。
7. **选中视觉**：TC 选中项文字变红（经典配色）+ 反色条；现状底色高亮 + 焦点描边
   （视觉已足够，但「勾选但非焦点」与「焦点但未勾选」的区分不如 TC 红字直观）。
8. **双栏方向**：TC 左右栏（可 Alt+方向键操作对面栏）；现状一致。
9. **窗口标题**：TC 显示当前路径；现状按 `sync_window_title` 规则（FM 未单独定制）。

## 四、与 TC 习惯相反或容易误操作的点（迁移成本）

1. **空格语义**：TC 默认空格 = 勾选文件并下移（在目录上才是算大小）；现状空格
   恒为目录大小计算，文件上无行为。TC 老用户会误算。
2. **Insert 勾选**：完全缺失，TC 用户的「空格/Ins 一路勾过去」肌肉记忆无处安放。
3. **F5 刷新错觉**：Explorer 用户按 F5 想刷新会触发复制对话框。
4. **字母定位**：TC/Explorer 都支持按首字母跳文件，现状无——长目录只能滚动或
   点过滤框，键盘流断裂感最强的一点。
5. **拖动即复制**：TC 拖动直拷，现状拖动必弹确认框——更安全但老用户嫌啰嗦。
6. **右键菜单项顺序**与 TC 差异大（现状对齐 Explorer 风格）；TC 用户找
   「压缩/解压」在 Alt+F5/F9 键位而非右键。
7. **过滤框位置**：TC 快速过滤浮在列表底部/顶部就近输入；现状在窗口最顶部右侧，
   且 Esc 语义（清过滤→清选择）与 TC（Esc 关面板）不同。

## 五、建议的优先级（按使用频率 × 实现成本）

**P0（高频刚需，成本中低）**
- ✅ 字母快速定位 / 增量搜索（type-to-select）（阶段 B：`Event::Text` 捕获进
  type-ahead 缓冲，命中即焦点+单选）
- ✅ Num* 反选、Num+/− 通配符选择组；「仅选文件」变体（阶段 A：egui 无小键盘
  键位，主键盘 `*`/`+`/`-` 经 `Event::Text` 捕获；选择组对话框含「仅选文件」）
- ✅ 按扩展名排序键（阶段 A：`SortKey::Ext`）
- ✅ 状态栏显示选中项总大小（阶段 A：文件直接求和；目录仅计入「计算大小」
  已缓存的值，不触发新计算）
- ✅ Ctrl+U 交换两栏、Ctrl+←/→ 目录传给另一栏、Ctrl+\ 根目录（阶段 B）
- ✅ 目录历史下拉（Alt+↓）（阶段 B）

**P1（价值高，成本中）**
- ✅ 缩略图视图（阶段 H：`ThumbCache` 两栏共享 + 可见范围代次节流；
  选择/过滤/键盘与列表模式完全共用）
- ✅ 栏内标签页（阶段 G：Ctrl+T 新建 / Ctrl+W 关闭 / Ctrl(+Shift)+Tab 循环，
  目录与活动索引持久化；TC 的锁定/重命名/标签组未做）
- ✅ 系统剪贴板互通（HDROP 复制/粘贴）+ 拖入/拖出 OLE（阶段 I：写系统剪贴板
  失败回退应用内；拖入经 `handle_dropped_files` 落点栏判定；拖出复用
  `drag_out` OLE HDROP）
- ✅ 批量重命名（阶段 F：Ctrl+M，纯函数计划 + 实时预览，逐项失败汇总）
- ✅ 进度条加单文件进度 + 速度/ETA（阶段 C：另有暂停/继续）
- ✅ Ctrl+Q 对面栏快速预览（阶段 D：双栏下非活动栏整栏替换为预览，焦点跟随）
- ✅ 分支视图（阶段 E：Ctrl+B，截断上限状态栏提示，面包屑 [分支] 标记）

**P2（锦上添花）**
- ✅ 搜索器（阶段 J：Alt+F7，名称通配/大小区间/日期/内容，结果「输送到焦点栏」
  分支视图 + 双击 reveal 跳所在目录）
- ✅ 系统属性对话框（Alt+Enter）/「打开方式…」（阶段 M：Windows shell 动词，
  非 Windows 隐藏）
- ✅ 新建文本文件（阶段 M：Shift+F4 / 右键，重名自动递增建议名）
- ✅ 面包屑可编辑路径输入（阶段 M：铅笔按钮 → TextEdit，Enter 导航 / Esc 还原 /
  无效红字保持编辑）
- ✅ 执行期冲突逐个询问（阶段 K：「逐个询问」档执行期真正逐条问，含双方大小/
  时间快照与「全部应用」；无缩略图对比）
